# Eight-stage prompt mapping

| Stage | Prompt focus | Time code |
| --- | --- | --- |
| 0 Export requirements | Export Confluence requirements and attachments | 00 |
| 1 Prepare documents | Convert and merge requirement documents | 01 |
| 2 Review requirements | Produce traceable review conclusions | 02 |
| 3 Generate test cases | Retain the session ID and remind the employee to continue stage 4 | 06 |
| 4 Generate smoke cases | Merge only a stage-3 record with the same session ID; otherwise record standalone | 06 |
| 5 AI comparison archive | Compare AI and manual cases, then archive | 05 |
| 7 Knowledge base | Extract reusable test knowledge | 07 |
| 8 SVN archive upload | Upload archive artifacts and record the result | 08 |

Use the Skill suite for detailed commands and authorization rules.
