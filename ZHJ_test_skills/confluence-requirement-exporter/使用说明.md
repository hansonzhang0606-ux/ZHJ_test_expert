# Confluence Requirement Exporter - 使用说明

## 1. 概述

将 Confluence 需求页面导出为 Word 文档，并下载全部附件图片。支持两种导出模式：

| 模式 | 触发词 | Word存放 | 附件存放 |
|------|--------|----------|----------|
| **ORIGINAL**（原需求） | 旧需求 / 原需求 / 历史需求 | `原需求\{标题}.doc` | `原图片\{标题}.zip`（打包，保留原始文件名） |
| **LATEST**（最新需求） | 新需求 / 最新需求 | `最新需求\{标题}\{标题}.doc` | `最新需求\{标题}\images\`（原始文件，不打包） |

## 2. 环境要求

- **Python 3.8+**（仅使用标准库，无需安装第三方包）
- **Confluence 账号密码**（HTTP Basic Auth，配置一次永久免密，不过期）
- 操作系统：Windows（输出路径为 Windows 格式）

## 3. 最简用法（推荐）：对话中直接输入

**不用改任何配置文件**，直接在 WorkBuddy 对话输入框发送即可。

### 首次使用：配置账号密码（一次性，永久免密）

首次使用时，在对话输入框发送账号密码，AI 自动创建本机配置文件（密码 base64 编码，不存明文）：

```
配置confluence：账号=你的账号, 密码=你的密码
```

AI 会自动创建 `~/.workbuddy/confluence_auth.json`，后续导出无需再输账号密码（永久免密，不过期）。

> 🔒 安全：账号密码只存在你本机 `~/.workbuddy/confluence_auth.json`（用户目录，不在项目路径），密码 base64 编码，不随项目复制泄露。

### 日常使用：直接发 URL

配置好后，直接发 URL 即可导出：

```
旧需求：https://finkms.kingdee.com/pages/viewpage.action?pageId=89883854
```

或

```
新需求：https://finkms.kingdee.com/pages/viewpage.action?pageId=100658642
```

AI 自动用本机配置的账号密码认证导出。

### 解析规则

- **`配置confluence：账号=xxx, 密码=yyy`**：首次配置，AI 创建本机配置文件（一次性）
- **`旧需求：` / `新需求：` 开头的一行**：页面 URL（或直接给 `pageId=数字`）
  - `旧需求` / `原需求` / `历史需求` → ORIGINAL 模式（doc + zip）
  - `新需求` / `最新需求` → LATEST 模式（文件夹 + images/）
- **账号密码认证**：本机配置文件，不过期，无需重复输入
- **Cookie（备选）**：如不走账号密码，也可用 `cookie: <Cookie>` 方式（见第 4 节，会过期）

## 4. 备选：Cookie 方式（账号密码为主，Cookie 为备选）

### 步骤
1. 浏览器打开目标 Confluence 页面（确认已登录能正常查看）
2. 按 **F12** 打开开发者工具 → **Network**（网络）标签
3. **刷新页面**（F5）
4. 点击列表第一个请求（通常是 `viewpage.action`）
5. 右侧 **Request Headers** → **Cookie** → 复制完整值

### 示例
```
JSESSIONID=ABC123DEF456; seraph.confluence=91167097%3A8c62fdf27120ee9ff514b1323da86bca53cd8685; acplatform_sid=xxx; acplatform_stk=xxx
```

**关键字段**：
- `JSESSIONID` - 会话 ID
- `seraph.confluence` - Confluence 认证令牌

> ⚠️ Cookie 会过期（通常几小时到几天），过期后导出会返回登录页，需重新获取。

## 5. 备选用法：命令行手动运行（跨电脑无 AI 时）

### 5.1 复制 skill 目录到目标电脑

```
confluence-requirement-exporter\
├── SKILL.md
├── 使用说明.md
├── scripts\
│   └── export_confluence.py
└── references\
    └── confluence_api.md
```

### 5.2 修改脚本中的输出目录（仅首次部署需改一次）

打开 `scripts\export_confluence.py`，修改顶部"PROJECT CONFIGURATION"区的路径，适配目标机器：

```python
BASE_URL = "https://finkms.kingdee.com"  # 自托管 Confluence 地址

WORD_OUTPUT_DIR       = r"D:\requirements\原需求"   # ORIGINAL 模式 Word 输出
ATTACHMENT_OUTPUT_DIR = r"D:\requirements\原图片"   # ORIGINAL 模式 zip 输出
LATEST_REQ_BASE       = r"D:\最新需求"               # LATEST 模式根目录
```

> cookie / pageId / mode 通过命令行传入，**不用改**；只有路径是按机器固定的，复制后调一次即可。

### 5.3 运行命令

```bash
# 导出原需求（打包 zip）
python export_confluence.py --page-id 89883854 \
    --cookie "JSESSIONID=ABC123; seraph.confluence=91167097%3Axxx" \
    --mode ORIGINAL

# 导出最新需求（存文件夹 + images/）
python export_confluence.py --page-id 100658642 \
    --cookie "JSESSIONID=ABC123; seraph.confluence=91167097%3Axxx" \
    --mode LATEST
```

参数说明：
- `--page-id`：Confluence 页面 ID（必填，从 URL `pageId=` 提取）
- `--cookie`：完整 Cookie 字符串（必填，会过期）
- `--mode`：`ORIGINAL` 或 `LATEST`（默认 `ORIGINAL`）
- `--base-url`：覆盖 Confluence 地址（默认 `finkms.kingdee.com`）

### 5.4 从 URL 提取 pageId

```
https://finkms.kingdee.com/pages/viewpage.action?pageId=89883854
                                                        ^^^^^^^^
                                                        这就是 pageId
```

## 6. 两种模式输出对比

### ORIGINAL（原需求）— 适合归档
```
requirements\
├── 原需求\
│   ├── V1.2 AI报表.doc
│   ├── V1.2 AI商品打折.doc
│   └── 零售版V1.1 收银_订单_会员_营销.doc
└── 原图片\
    ├── V1.2 AI报表.zip                 (12张PNG)
    ├── V1.2 AI商品打折.zip              (15张PNG)
    └── 零售版V1.1 收银_订单_会员_营销.zip (84张PNG)
```
- 每个需求一个 doc + 一个 zip
- zip 内保留原始图片文件名
- 适合长期归档，节省空间

### LATEST（最新需求）— 适合查看
```
最新需求\
└── 智慧记零售版本 V1.6.1\
    ├── 智慧记零售版本 V1.6.1.doc
    └── images\
        ├── image2026-7-20_15-13-3.png
        ├── image2026-7-20_15-12-54.png
        └── ...
```
- 每个需求一个独立文件夹
- 图片可直接查看，无需解压
- 适合当前版本的需求文档查看

## 7. 常见问题

**Q: 提示 HTTP 404 / Could not get page title**
A: Cookie 过期了。重新从浏览器获取 Cookie，在对话里重发（带 `cookie:` 前缀）即可。

**Q: Word 导出被标记为"登录页面"**
A: 不用担心。Confluence 的 Word 导出是 MHTML 格式，文件头含 `MIME-Version` 和 `multipart/related`，是有效 Word 文档，脚本已做正确识别。

**Q: 文件名含 `/` 等非法字符报错**
A: 脚本自动将 `\ / : * ? " < > |` 替换为 `_`，无需手动处理。例：`收银/订单/会员` → `收银_订单_会员`。

**Q: 附件很多（200+）只下了部分**
A: 脚本已支持分页（`?limit=200&start=200`），理论上无上限。

**Q: 其他机器路径不同怎么办**
A: 只需改脚本顶部 `PROJECT CONFIGURATION` 里的三个目录常量，cookie/pageId/mode 始终走命令行，不动。

**Q: 换其他公司的 Confluence**
A: 命令行加 `--base-url https://confluence.yourcompany.com`，或改脚本顶部 `BASE_URL`。

**Q: 有账号密码能否免 Cookie**
A: 可配 MCP 连接器（`@enjoyzl/mcp-server-confluence-ts`，支持用户名+密码），需 Node.js 环境。详见 SKILL.md。
